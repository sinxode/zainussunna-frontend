# Zainussunna Academy — Calendar Fund Management System (Frontend)

Modern React + TypeScript + Vite frontend for Zainussunna Academy Calendar Manager (ZCM).

## Architecture

- **Stack**: React 18, TypeScript, Vite, SCSS Design Tokens, Lucide Icons
- **Deployment Platform**: Vercel
- **Production Domain**: `https://calendar.zainussunnaacademy.com`
- **Backend API**: `https://api-calendar.zainussunnaacademy.com`

## Environment Variables

| Variable | Description |
|---|---|
| `VITE_API_URL` | Set to `https://api-calendar.zainussunnaacademy.com` for production builds |

## Local Development & Build

```bash
npm install
npm run dev
npm run build
```
